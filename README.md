### What you need to RUN THE PROGRAM 
TO run the program you need Java 25 , You can download it from here :- https://www.oracle.com/java/technologies/javase/jdk25-archive-downloads.html
After Downloading and ensuring that the Java is successfully running on the Console and the Path is Set for JAVA 
Download the .jar file from the releases then On terminal type:- 
`java -jar "Filename.jar"`
Replace the Filename.jar with the Name of the File that you have downloaded from the releases !
